# 하루말 어학실

혼자 쓰는 일본어·영어 학습 웹앱(PWA)입니다. 휴대폰 홈 화면에 설치해서 앱처럼 씁니다.

회화 중심 단계형입니다. 언어마다 1~6단계가 있고, 단계마다 난이도 3칸이 있습니다. 매일 보는 **오늘의 시험** 점수로 한 칸씩 오르내립니다 (`js/curriculum.js`).

표현은 단계마다 다섯 주제로 나뉩니다: 일상 · 가족 · 집 · 가벼운 대화 · 사업 (생활 표현은 `js/life.js`).

| 단계 | 일본어 | 영어 |
|---|---|---|
| 1 입문 | 인사 · 집에서 쓰는 한마디 | 일상 반응 · 집에서 한마디 |
| 2 초급 | 가족 소개 · 가게 · 집안 생활 | 가게 · 식당 · 가족 소개 |
| 3 초급 | 가벼운 대화 · 주말 · 아이 이야기 | 스몰톡 · 주말 · 집 생활 |
| 4 중급 | 회사 생활 · 집안일 · 가족 계획 | 메신저 소통 · 집안일 · 가족 계획 |
| 5 중급 | 비즈니스 인사 · 전화 · 근황 대화 | 이메일 · 회의 · 근황 |
| 6 중상급 | 회의 · 거래 · 협상 · 의견 나누기 | 무역 · 협상 · 의견 나누기 |

- **오늘의 시험** (첫 화면 맨 위, 하루 한 번): 10문제. 생활(일상 · 가족 · 집 · 가벼운 대화) 6 : 사업 4로 골고루, 덜 익힌 것과 북마크한 것을 먼저 냄
  - 9개 이상이면 난이도 한 칸 ↑, 8개를 이틀 연속이면 한 칸 ↑, 4개 이하면 한 칸 ↓. 3칸을 다 채우면 다음 단계
  - 칸이 오를수록 다음 단계 ‘도전’ 문제와 어려운 유형이 늘어남: 1칸(뜻 고르기 · 한국어 보고 고르기 · 듣기), 2칸(+ 문장 고르기, 도전 2), 3칸(듣기 · 문장 위주, 도전 4)
  - 같은 날 다시 보면 연습 시험(난이도 그대로). 틀린 표현은 자동 북마크
- **말하기 연습** (오늘 화면): ① 새 표현 3개 익히기 ② 한국어 보고 소리 내어 말하기 (마이크로 확인, 일치율 70% 이상이면 정답. 마이크 없이 스스로 채점도 가능) ③ 듣고 뜻 고르기. 끝나면 AI 회화 미션으로 이어짐. 처음엔 시작 단계를 고름
- **단계**: 지금 단계와 난이도 칸, 진행률(서로 다른 날 2번 이상 맞힌 표현 = 익힘), 이 단계 표현을 주제별로, 단계 바꾸기, 복습 퀴즈(섞어 풀기 · 단어 · 한자 · 숙어 · 표현 · 북마크)
- **회화**: 오늘의 미션(지금 단계 장면 + 오늘 익힌 표현을 쓰도록 AI가 대화를 이끔)과 자유 대화. ‘평가 받기’를 누르면 유창성 · 정확성 · 자연스러움 1~5점, 잘한 점, 고칠 문장 3개, 미션 표현 사용 여부
- **실력**: 지금 단계·난이도 칸과 6단계 길, 익힌 표현 · 말하기 성공 · 회화 평가 · 오늘의 시험 · 연속 기록, 매일 시험 점수 그래프(칸 오르내림 표시), 최근 회화 평가 평균과 추이
- **복습 퀴즈**: 4지선다. 일본어 단어·한자(한국 한자 훈음)·숙어·표현, 영어 단어 50 · 숙어 35 (`js/business-en.js`). 모르면 "모르겠어요", 더 알고 싶으면 "자세히 설명 보기"(Claude)
- **표현 데이터**: 일본어 일상 + 비즈니스 58개 (`js/phrases.js`) + 생활 58개 (`js/life.js`), 영어 일상 회화 28개 (`js/daily-en.js`) + 생활 46개 (`js/life.js`) + 비즈니스·무역·이메일·왓츠앱 68개
- **정답 화면**: 예문 1개 (예문 더 보기로 3개까지), 한자는 그 한자가 들어간 말
- **한자 뜻 힌트**: 일본어 단어·숙어·표현 아래에 들어간 한자의 훈음 (예: 天気 → 天 하늘 천 · 気 기운 기)
- **따라 말하기**: 문장을 읽으면 일치율 (Azure Speech 키가 있으면 발음 점수)
- **간격 반복 복습**: 틀린 건 5분 뒤, 맞힌 건 1·3·7·14·30·60일 간격
- **연속 학습**: 하루 10문제를 채운 날이 이어지면 🔥 N일 연속 (첫 화면 카드, 이번 주 달성, 최고 기록, 달성 축하)
- **북마크**: ☆로 표시한 것은 오늘의 퀴즈에 2개씩 더 나오고, 모아 보기·북마크만 풀기 가능
- **효과음**: 맞힘·틀림·세트 완료·연속 달성 (설정에서 끌 수 있음)

서버 없이 동작합니다. API 키는 앱 설정 화면에서 입력하고 **그 기기의 브라우저에만** 저장됩니다. 코드나 저장소에는 키가 들어가지 않습니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 화면 골격 |
| `css/app.css` | 스타일 (라이트·다크 모드) |
| `js/app.js` | 화면과 학습 로직 |
| `js/content.js` | 기본 단어·한자·숙어·회화 상황 |
| `js/curriculum.js` | 회화 단계 1~6: 단계별 주제(일상 · 가족 · 집 · 가벼운 대화 · 사업) 표현과 AI 대화 장면 |
| `js/life.js` | 생활 표현 (일본어 · 영어): 일상 · 가족 · 집 · 가벼운 대화, 단계별 |
| `js/daily-en.js` | 하루말 영어: 어른의 일상 회화 표현 (기본 반응 · 식당·가게 · 스몰톡·여행) |
| `js/phrases.js` | 일본어 일상·비즈니스 표현 (예문 3개씩) |
| `js/business-en.js` | 하루말 영어: 비즈니스·무역·이메일·왓츠앱 표현·숙어·단어 |
| `js/family-en.js` | 하루영어: 초등 아이와 집에서 쓰는 표현·숙어·단어 |
| `js/examples.js` | 단어·한자·숙어의 추가 예문 |
| `js/kanji-meaning.js` | 한자 훈음 (힌트용) |
| `js/streak.js` | 연속 학습 계산과 첫 화면 카드 (하루말·하루영어 공용) |
| `js/ai.js` | Claude API 호출 (회화, 회화 평가, 콘텐츠 생성) |

| `js/store.js` | 기기 저장, 백업 |

빌드 과정이 없습니다. 파일을 그대로 올리면 됩니다.

## 내 PC에서 실행

```bash
python -m http.server 5173
```

브라우저에서 http://localhost:5173 을 엽니다. 마이크는 `localhost` 또는 `https://` 주소에서만 동작합니다.

## 1. Claude API 키 (AI 회화, 콘텐츠 생성)

1. https://console.anthropic.com 에 가입하고 결제 수단을 등록합니다.
2. **Settings → Limits**에서 월 사용 한도를 정해 둡니다 (예: $10).
3. **API Keys → Create Key**로 키를 만들고 복사합니다.
4. 앱의 **설정 → Claude → API 키**에 붙여 넣고 **연결 테스트**를 누릅니다.

모델은 설정에서 고를 수 있습니다. 기본값은 Claude Opus 5.5이고, 비용을 줄이려면 Claude Haiku 5.5로 바꾸면 됩니다.

## 2. Azure Speech 키 (원어민 음성, 발음 점수) — 선택

없어도 앱은 동작합니다(휴대폰 기본 음성과 기본 음성 인식 사용).

1. https://portal.azure.com 에 가입합니다 (본인 확인용 카드 등록이 필요할 수 있어요).
2. **리소스 만들기**에서 `Speech`(음성 서비스)를 검색해 만듭니다.
   - 지역: **Korea Central**
   - 가격 책정 계층: **Free F0** ← 한도를 넘으면 과금되지 않고 멈춥니다.
3. 만든 리소스의 **키 및 엔드포인트**에서 **키 1**과 **위치/지역**을 확인합니다.
4. 앱의 **설정 → Azure Speech**에 키를 넣고 지역을 고른 뒤 **음성 테스트**를 누릅니다.

## 3. 배포 (휴대폰에서 쓰기)

### Cloudflare Pages (비공개 저장소도 무료)

1. 이 폴더를 GitHub 저장소(비공개)에 올립니다.
2. https://dash.cloudflare.com → **Workers & Pages → 만들기 → Pages → Git에 연결**에서 저장소를 고릅니다.
3. 빌드 설정: 프레임워크 **없음**, 빌드 명령 **비움**, 출력 디렉터리 `/`.
4. 배포가 끝나면 `https://<프로젝트이름>.pages.dev` 주소가 생깁니다. 이후 GitHub에 올릴 때마다 자동으로 다시 배포됩니다.

### GitHub Pages

공개 저장소이거나 조직이 GitHub Team 이상이면 저장소의 **Settings → Pages → Deploy from a branch → main / (root)** 로 바로 배포할 수 있습니다.

## 4. 휴대폰에 설치

- **아이폰**: Safari로 배포 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열고 → 메뉴(⋮) → **앱 설치** (또는 앱 설정 화면의 **앱 설치** 버튼)

설치 후 앱의 설정에서 API 키를 한 번 넣습니다. 키와 학습 기록은 기기마다 따로 저장됩니다.

## 데이터와 보안

- 학습 기록은 기기의 브라우저 저장소에 있습니다. **설정 → 데이터 → 백업 내보내기**로 가끔 백업해 두세요. 백업 파일에는 API 키가 들어가지 않습니다.
- API 키는 저장소에 절대 커밋하지 않습니다 (`.gitignore`에 백업 파일과 `.env`가 들어 있어요).
- 키가 노출된 것 같으면 각 콘솔에서 키를 지우고 새로 만듭니다.

## 하루영어 (`easy/`)

아내용으로 만든 쉬운 영어 퀴즈 앱입니다. 주소: https://help153.github.io/harumal/easy/

- 영어만, 퀴즈 위주: 아이와 집에서 쓰는 생활영어 120 · 단어 60 · 숙어 35 (`js/family-en.js`)
- 오늘의 퀴즈 10문제 (생활영어 4 · 초등단어 4 · 숙어 2), 틀린 문제는 세트 끝에 한 번 더
- 문제가 나오면 영어를 읽어 주고, 답을 고르면 정답을 읽어 줌
- Claude API 키를 넣으면 '자세히 설명 보기' 사용 가능 (선택)
- 하루말과 같은 주소에 있지만 저장 공간(`haruen:`)과 서비스 워커는 따로 씀
- 하루말의 `css/app.css`, `js/ai.js`, `js/speech.js`를 함께 사용하므로 그 파일을 고치면 하루영어에도 반영됨
